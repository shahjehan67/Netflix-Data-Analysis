# Netflix-Data-Analysis
# 🎬 Netflix Data Analysis (EDA)

Data Science project! In this project, I performed Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

## 📊 Project Overview
The goal of this project is to analyze Netflix's content catalog to find interesting trends, patterns, and insights, such as:
- Comparing the ratio of Movies vs. TV Shows.
- Finding out which years had the highest content releases.
- Identifying the top countries producing content on Netflix.

## Tech Stack Used
- **Python**
- **Pandas & NumPy** (For Data Manipulation)
- **Matplotlib & Seaborn** (For Data Visualization)

## 📈 Key Insights
1. **Movies vs TV Shows:** Netflix has a significantly higher number of Movies compared to TV Shows.
2. **Release Trends:** Content production spiked rapidly post-2015.
3. **Top Country:** The **United States** produces the highest amount of content on Netflix, followed by other nations like India.

## How to Run
You can open the `.ipynb` file directly in Google Colab or Jupyter Notebook to view the complete code and visualizations.
